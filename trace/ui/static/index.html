Interview (what the data couldn't reveal)

      

        
        
        
      

      

      
For each approved workflow, Trace asks a few short, triaged
        questions about what capture couldn't see (the destination tab, one-vs-many
        layout) or couldn't decide (conflict rules). Answer one line each, or skip —
        skips fall back to reading the live environment and are flagged in the
        grounding record. Answers become authoritative inputs to the config.

    


    
    

      
Build & test agents (config + sandbox logic gate)

      

      

        
        
      

      

      

        
        
      

      
Generates each agent's configuration directly
        (agent_<id>.test.yaml / .live.yaml +
        grounding_<id>.json), then runs a hidden logic gate:
        the test agent runs in a sealed sandbox and a grader checks its reasoning
        before it can advance. Only agents that pass advance; the gate is not
        shown to the worker. See the agents tab. Clean up platform
        deletes the sandbox sessions and agents Trace created — only when you press it.

    


    
    

      
Connect your apps (Pipedream — two OAuth taps)

      

        
        
        
        
      

      

      

      
Trace connects each app through Pipedream — you never create a
        Pipedream or Claude account. Tap Connect, then approve in Google's window
        (the only step Trace can't absorb). Trace binds the credential into a vault for
        you. A connected account that doesn't match your confirmed email is
        flagged and not used. This is a dev build: Google's window is
        simulated by "Simulate Allow".
